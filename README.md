**CyberOS v8** هي منصة متكاملة للأمن السبراني، فحص الشبكات، التحليل الجنائي، وتقييم الثغرات بالذكاء الاصطناعي، مصممة خصيصاً لبيئات **Termux** و **Linux**.

---

## 🚀 المميزات والوحدات (Modules)

| # | الموديول | الوصف |
|---|---|---|
| **1** | **Network Tools** | أدوات فحص وتتبع الشبكات وتحليل المنافذ (Port Scanning & Analysis). |
| **2** | **Security Tools** | مجموعة أدوات الأمان وفحص الثغرات الأمنية المتقدمة. |
| **3** | **Subnet Host Sweeper** | اكتشاف الأجهزة والـ Hosts النشطة على نطاقات الشبكة المحلية. |
| **4** | **OSINT Digital Footprint** | البحث واستخراج الأثر الرقمي للحسابات عبر المنصات المختلفة. |
| **5** | **AI Vulnerability Assessment** | تقييم مستويات المخاطر والأمن السيبراني باستخدام الذكاء الاصطناعي. |
| **6** | **Web Directory Fuzzer** | فحص المسارات المخفية ولوحات التحكم والملفات للروابط والمواقع. |
| **7** | **Cyber Password Generator** | إنشاء كلمات مرور معقدة وعالية التشفير والتعقيد. |
| **8** | **Terminal QR Tools** | إنشاء وقراءة رموز الـ QR مباشرة من داخل الطرفية. |
| **9** | **Audit Logs Viewer** | عرض وفحص سجلات العمليات والفحوصات القادمة من قاعدة البيانات SQLite. |
